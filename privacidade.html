Política de privacidade do Segundo Cérebro

O Segundo Cérebro é um assistente pessoal de uso exclusivo de Michelder Januario (micheldersj@gmail.com). Não é oferecido ao público.

Dados acessados. Com a autorização do próprio dono da conta, o app lê eventos do Google Agenda, cria e altera compromissos quando ele pede, lê e-mails recebidos no Gmail para resumir e lembrar o que é importante, e cria rascunhos de e-mail. Nenhum e-mail é enviado automaticamente.

Uso. Os dados servem apenas para organizar a rotina do próprio usuário. Não são vendidos, compartilhados com terceiros nem usados para publicidade. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento. Tokens de acesso ficam criptografados em banco de dados privado (Supabase). O processamento de texto usa provedores de IA (Anthropic e OpenAI) apenas para gerar respostas e resumos.

Exclusão. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Pedidos de exclusão: micheldersj@gmail.com.
